# 어둠의 계승자 — 웹사이트 배포판

정적 사이트입니다. `index.html` 파일 하나로 구성되어 있으며 서버 측 코드가 필요하지 않습니다.

## Vercel 배포
1. Vercel에 로그인합니다.
2. 이 폴더를 GitHub 저장소에 업로드하고 Vercel에서 해당 저장소를 Import 합니다.
3. Framework Preset: Other, Build Command: 없음, Output Directory: 비워두거나 프로젝트 루트.
4. Deploy를 누르면 HTTPS 주소가 생성됩니다.

## 주의
캐릭터 저장은 브라우저의 로컬 저장소를 사용합니다. 브라우저나 기기를 바꾸면 자동으로 동기화되지 않습니다. 백업 기능을 사용하세요.
